Objetivo do Projeto: Utilizar Scikit-Learn Para Classificar os 3 Tipos de Flores, 
e Conseguir predizer quais dados são Agrupados e quais dados das Flores são Separados e Confusos.

Bibliotecas Usadas: Scikit-Learn, MatplotLib, Numpy, Pandas

Como Executar: Você Precisa insalar o MatPlotLib, Pandas e o Scikit-Learn (pip install Scikit-Learn, Pandas, MatPlotLib).

O Que o Gráfico representa: Ele representa 3 classes de Flores (Versicolor, Setosa e Virginica), 
aonde conseguimos assimilar sua Largura e Altura com numeros dados pela Analise de dados do Pandas.
Vendo a Altura e Largura das Sepalas e Altura e Largura das Pétalas.

O Que aprendi: Aprendi a utilizar Scikit-Learn Com base em Analises, com isso e aprimorando... com o Problema que surgir,
posso utilizar o melhor algoritmo para resolver algum problema.
